# Zeus

**Zeus** is a multi-agent desktop + mobile control plane for AI coding runtimes. It keeps the compact, always-available interaction *idea* that makes tools such as Coucou useful, while using its own black-dog identity and a provider-neutral protocol.

## What is in this repository

- `gateway/` — Go VPS service: pairing, device auth, sessions, SSE events/actions, provider proxy and persistence.
- `adapters/` — dependency-free hooks for Codex, Claude Code, Antigravity, plus a generic event emitter.
- `apps/mobile/` — Flutter / Riverpod / FlutterGen / Rive iOS + Android controller with an interactive fallback until the production layered `.riv` is exported.
- `apps/desktop-macos/` — native SwiftUI + AppKit floating/notch controller.
- `apps/desktop-windows/` — Tauri 2 + TypeScript controller (also usable as the Linux desktop base).
- `packages/protocol/` — normalized Zeus Agent Protocol schemas.
- `shared/branding/` — original Zeus dog assets; no Coucou/Mochi artwork.

## Runtime vs model provider

Zeus intentionally separates the runtime executing the work from the model/API behind it.

**Runtime adapters:** Codex, Claude Code, Antigravity, Generic.  
**Model/API providers:** OpenAI, DeepSeek, Gemini, Anthropic, OpenRouter, Ollama, or another compatible endpoint.

This lets a future runtime or provider be added without rewriting the apps.

## Fast VPS start

```bash
cd gateway
cp .env.example .env
cp providers.example.json providers.json
# Edit both tokens and only the provider keys you use.
docker compose up -d --build
```

Keep port 8080 bound to localhost and publish it through HTTPS (Caddy/Nginx/Traefik). See `docs/VPS.md`.

Create a mobile/desktop pairing code:

```bash
export ZEUS_GATEWAY_URL=https://zeus.your-domain.com
export ZEUS_ADMIN_TOKEN='...'
./zeusctl pair
```

## Agent computer

Set these variables on every computer running an adapter:

```bash
export ZEUS_GATEWAY_URL=https://zeus.your-domain.com
export ZEUS_AGENT_TOKEN='...'
export ZEUS_MACHINE_NAME='Office PC'
# opt in only if you want the remote phone to answer supported approval prompts:
export ZEUS_REMOTE_APPROVALS=1
```

Then install the hook configuration for your runtime from `adapters/<runtime>/`.

## Mobile

The Flutter client uses Riverpod for state, FlutterGen for typed assets, secure storage for the paired token and a Rive contract for the mascot. Rive source/build tooling is included, and a code-animation fallback remains functional until the final layered `zeus.riv` is exported.

```bash
cd apps/mobile
./scripts_bootstrap_platforms.sh
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```

On iOS 26+, apply the included `UIGlassEffect` platform-view patch described in `apps/mobile/README.md` so native Liquid Glass backs the Flutter controls.
